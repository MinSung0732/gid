# Harmony balance editor

브라우저 UI가 아니라 소스에서 전역 밸런스 숫자를 쉽게 조정하기 위한 폴더입니다.

## 수정 위치

- `deck.js`: 시작 덱, 기본 덱 한도, 최소 덱
- `player.js`: HP, AP, 손패, 드로우, 포션, 불순물 손패 규칙
- `economy.js`: 포션과 연구실 가격
- `rewards.js`: 보상 후보 소진 시 대체 골드
- `campaign.js`: 도감 진행 보너스의 해금률과 지급량
- `combat.js`: 전투 공통 제한

카드·증강·적 하나에만 적용되는 수치는 기존 카드/증강/몬스터 데이터 파일에서 수정합니다.
일반 방의 골드와 티어 확률은 `data.js`의 `TABLES`, 보상 후보 수는 `reward-system.js`의
`REWARD_PROFILES`, 아틀리에 가격은 `atelier-shop.js`에서 수정합니다. 이 값들은 이미 표 형태로
모여 있어 이 폴더로 복제하지 않습니다.

## 보호되는 조건

- 최소 덱 ≤ 시작 덱 ≤ 기본 덱 한도
- 기본 턴 AP ≤ AP 한도
- 첫 턴/일반 드로우 ≤ 손패 한도
- 시작 포션 + 도감 보너스 포션 ≤ 포션 한도
- 도감 보너스 해금률은 0~1이며 오름차순
- 가격과 보상은 음수가 될 수 없음
- 시작 덱 수를 바꾸면 기본/추천 덱은 1티어 카드와 `maxCopies` 안에서 자동 보정
- 최대 덱을 낮춘 경우 기존 일반 세이브는 로딩 시 새 한도까지 잘릴 수 있음

막의 방 구성과 개수는 순서 자체가 게임 규칙이므로 `data.js`의 `ROUTE` 배열에서 조정합니다.

수정 후 저장소 루트에서 `npm run check`, `npm test`, `git diff --check`를 실행합니다.
