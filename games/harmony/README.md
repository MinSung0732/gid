# Project Harmony — 로컬 프로토타입

저장소 루트에서 `npm start` 후 http://127.0.0.1:5173/games/harmony/ 로 접속합니다.
공개 게임 목록에는 아직 등록하지 않았습니다. 외부 패키지·서버 DB 없이 동작합니다.

- 12노드, 카드 전투, 보스 3회, 채집/황금방, 휴식/카드 강화, 카드 제거/포션 상점
- 초기 HP 80, AP 3, 매 턴 5장·최대 7장, 적 인텐트, 일반·엘리트 15턴/보스 20턴부터 관통 폭주
- 18개 아이템 계열 × 4등급 = 72개 테이블 항목. 종류 추첨 후 등급/아이템 추첨
- 모든 아이템 즉시 획득·적용, 동일 효과 합산. AP 8, 방어 보존 90%, 흡수 100 제한
- 조건부 카드 해금 3개, 발견 도감, 전투 중 저장/이어하기, 결과, 무한 루프
- 실험실: 방별 추첨 및 1,000회 통계. 별도 난수 사용, 런/도감 변경 없음

테이블/카드 조정: `data.js`. 전투/보상 규칙: `engine.js`. 화면: `main.js`, `styles.css`.
검증: `node scripts/test-harmony.mjs` (저장소 루트에서 실행).

현재 단계에서는 경로가 고정이며 방의 보상이 무작위입니다. 특성/유물의 영구 해금 확대,
상점 유물 구매, 분기 경로, 모바일 연출, 결과 이미지/카카오 공유, 실제 쿠폰은 후속 범위입니다.
무한 루프는 HP ×1.85, 공격 ×1.3; 심연 2부터 첫 턴 비용 +1, 심연 3부터 턴마다 오염.
피해 반사/면역 루프 페널티는 적용하지 않았습니다. 10~15분은 목표이며 실측 밸런싱 전입니다.
제품 그림은 기존 게임용 일러스트입니다. 상품 상세의 공식 사진으로 사용하지 않습니다.
