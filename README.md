# 결이든 미니게임

결이든 퍼퓸 스톤 디퓨저 오브제 볼케닉 & 크리스탈 세트를 위한 로컬 프로젝트입니다.

## 현재 범위

- 모바일과 PC에 대응하는 브랜드 시작 화면
- 전달받은 브랜드 색상 6종을 CSS 공통 변수로 정의
- 브랜드명, 제품명, 제품 종류 기본 설정
- 추가 패키지 설치 없이 실행하는 로컬 개발 서버

‘향을 담는 돌’ 게임 구현 완료: 스톤 3종 선택, 30초 타이밍 게임, 점수 및 콤보, 기기 내 최고 기록, 일시정지, 결과 공유, 선택형 효과음.
터치/클릭 또는 스페이스 키로 방울을 떨어뜨리고 Escape 키로 일시정지합니다. 스페이스 키는 플레이 중 낙하에만 사용하며 시작·재시작·재개는 하지 않습니다. 다른 탭으로 전환하면 자동으로 일시정지합니다.
콤보에 따라 옅은 향과 집중선이 강해지고 10콤보마다 다른 포즈의 사람이 한 명씩, 최대 5명까지 슬라이드로 등장합니다. 콤보가 끊기면 효과가 옅어지며 사람들이 퇴장하고, 재시작 시 초기화됩니다. 모션 감소 설정에서는 캐릭터 슬라이드와 흔들림을 생략합니다.
중앙 기준 판정: 8.5px 이내 PERFECT(100점), 24px 이내 EXCELLENT(80점), 44px 이내 GOOD(50점), 66px 이내 NOT BAD(25점), 그 밖은 BAD(0점, 콤보 초기화). 좌우 동일하며 화면 크기와 무관한 게임 내부 좌표 기준입니다. 연속 성공마다 10점씩 최대 100점 보너스를 더합니다.
`npm test`로 판정 경계와 게임 진행·정지·종료·재시작을 검사합니다.
공식 마스코트 원본을 `public/assets/mascot.png`로 저장하면 PC 안내 영역에 자동 표시됩니다. 현재 캐릭터 원본 파일은 없으며 돌은 게임용 도형으로 표현했습니다.
Android APK 패키징은 아직 구현 전입니다.
현재 폴더는 웹 소스의 출발점이며 외부에 배포되지 않았습니다.

## 실행

Node.js 설치 환경에서 이 폴더를 터미널로 열고 실행합니다.

```sh
npm start
```

브라우저 주소: http://127.0.0.1:5173

## GitHub Pages 배포 및 기록 자랑하기

이 폴더 안의 파일들을 GitHub 저장소 루트에 올립니다. `index.html`이 저장소 최상위에 있어야 합니다.
저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택하고, 업로드한 브랜치(일반적으로 main)와 /(root)를 선택해 저장합니다.
배포된 주소에서 플레이한 뒤 ‘내 기록 링크로 자랑하기’를 누르면 돌 종류, 점수, 최고 콤보, 성공 횟수를 포함한 링크가 공유됩니다.
친구가 링크를 열면 해당 결과와 ‘나도 도전하기’ 버튼이 표시됩니다. 친구 기록은 자신의 최고 기록으로 저장되지 않습니다.
저장소 이름이 포함된 하위 경로에서도 동작하며 별도 서버나 빌드가 필요하지 않습니다.
기록은 URL에 담긴 자랑용 데이터로, 수정 가능한 값입니다. 공식 랭킹이나 경품 검증에는 사용하지 않습니다.
메신저 링크 미리보기에 개인별 점수 이미지를 생성하는 기능은 포함하지 않습니다. 점수는 링크를 연 게임 화면에 표시됩니다.

문법 검사: `npm run check`

## 파일

- `index.html`: 브랜드 시작 화면
- `src/styles.css`: 브랜드 색상과 반응형 스타일
- `src/main.js`: 브랜드 정보 및 향후 게임 진입점
- `public/assets/`: 제품 사진 및 로고 보관 위치
- `scripts/serve.cjs`: 로컬 개발 서버
